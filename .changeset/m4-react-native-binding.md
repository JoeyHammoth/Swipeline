Add `@swipeline/react-native`, a React Native and Expo binding for `SwipeDeck`. It renders the shared card templates and string catalog, drags with `PanResponder` so no Gesture Handler or Reanimated install is needed, announces cards through `AccessibilityInfo`, and shares `computeSwipeIntent` with the web bindings. Not yet run on a device.
