# Strings and locales

Bindings render their own chrome — buttons, status messages, the live-region
announcement — from a catalog. Card text is user data and is never translated.

```ts
import { createTranslator, en } from '@swipeline/i18n'

const t = createTranslator({ 'actions.like': 'Gefällt mir' }, { locale: 'de' })
t('deck.empty') // falls back to English
t.missing // keys neither catalog defines
```

## Passing a catalog to a binding

```tsx
<SwipeDeck store={store} messages={de} locale="de-DE" />
```

```ts
const deck = document.querySelector('swipe-deck')
deck.messages = de
```

A partial catalog is valid: any key it omits falls back to English, and the
translator records the missing ones. That makes a half-finished translation
shippable — it reads in English rather than showing raw keys.

## Keys

| Key | English |
|---|---|
| `deck.label` | Swipe deck |
| `deck.loading` | Loading cards… |
| `deck.empty` | No more cards. |
| `deck.offline` | You are offline. Cards you already loaded are still available. |
| `deck.reconnect` | Reconnect |
| `deck.retry` | Retry |
| `deck.undo` | Undo |
| `deck.undoAria` | Undo last swipe (U) |
| `deck.tags` | Tags |
| `deck.facts` | Details |
| `deck.announce` | `{title}, card {position}` |
| `error.load` | Could not load cards. |
| `actions.like`, `actions.dislike`, `actions.superlike`, `actions.later`, `actions.skip` | Button labels |

`en` exports exactly this set, so it is the file to copy.

## What is localised, and what is not

- **Localised:** controls, status messages, the announcement, the facts strip
  heading and the `aria-label` of each button.
- **Formatted, not translated:** numbers in the `facts` template, through the
  binding's `locale` (`4.6` in English, `4,6` in German).
- **Not localised:** card titles, bodies, tags, fact labels and attribution — they
  come from the source and from the deck's own manifest.

## Rules

1. **Never concatenate translated fragments.** `deck.announce` is one template with
   `{title}` and `{position}` because word order differs between languages.
2. **An unknown placeholder stays visible.** `formatMessage('{title} {nope}')`
   leaves `{nope}` as written, so a missing parameter fails review instead of
   shipping `undefined`.
3. **Action keys follow the action name.** A custom action (`actions.right: 'buy'`)
   uses `actions.buy`; when the catalog has no entry, the binding keeps the
   English label the gesture layer supplies.
4. **RTL is a layout concern, not a catalog one** — see [Theming](/reference/theming).
